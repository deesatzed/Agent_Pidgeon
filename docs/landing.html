Pidgin is not telemetry and not a prompted auditor agent.

The trust path is deterministic. LLMs can help author and explain, but they do not decide pointer truth.

Telemetry

Excellent for spans, logs, metrics, and latency. It usually records runtime behavior after a service does something.

Auditor agent

Useful for narrative review, but it is still a model opinion. The same prompt can drift across models, context, and time.

Agent Pidgin

Validates schema, enforces policy, resolves trusted catalogs, detects semantic drift, and emits replayable receipts.
