# A2A Wrapper Example

This example shows a Pidgin contract embedded in an A2A-style task artifact.

There is no A2A SDK dependency. The point is the shape of the data:

1. A2A carries the task.
2. The task includes a Pidgin semantic contract.
3. Agent Pidgin resolves the contract locally.
4. The receiver returns receipts and an implementation plan.

Agent Pidgin complements A2A. It does not replace A2A transport.
